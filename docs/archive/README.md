# Historical Archive

Start with the [current documentation](../README.md) for setup and features.

- `team_prototype/`: shared prototype through Week 8, including the notebook,
  old app, and RAG experiment.
- `class_docs/`: planning, specifications, independent-work log, and retired
  coursework helpers. Original dates and claims are preserved.
- `old_screenshots/`: earlier app captures, not the current interface.
- `design/`: simulated HTML dashboard used as the design reference. Its controls
  and numbers are not evidence of real analytics.

Preserved scripts are not maintained execution paths. Archiving preserves
collaborators' contributions and historical context.
